# Market-data integrity

MandiMitra separates two classes of information:

1. **Official published records:** returned by the optional Python connector from AGMARKNET/data.gov.in after an API key and valid resource ID are configured.
2. **Illustrative estimates:** the supplied local mandi ranking, transport/fee estimates, 14-day history and five-day forecast. These remain estimates until the project is connected to verified historical and current market records and the forecast is recalibrated.

The interface labels these separately. Do not describe the illustrative estimates as live or guaranteed prices during a demo.
